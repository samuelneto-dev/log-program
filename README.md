# 🧠 Lógica de Programação — SENAI

## 📌 Descrição
Repositório com exercícios e estudos de **lógica de programação** desenvolvidos durante o curso no SENAI, organizados por linguagem.

## 🎯 Objetivo
Praticar e consolidar os fundamentos da lógica de programação (variáveis, condicionais, laços, vetores e funções) em duas linguagens diferentes.
